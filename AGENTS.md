# AGENTS.md

This repository is a Claude Code skill called `flow-trace`. It builds interactive, step-through visualizations of how a request, job or feature moves through a codebase file by file, with the real code at every hop.

- Asked to **install this skill** into a project or a machine: follow `INSTALL.md` step by step and report the verification output.
- Asked to **use** the skill (visualize, trace, walk through, or diagram a code flow): read `SKILL.md` and follow it.
- Asked to **change** this repository: read `CLAUDE.md` first; it holds the rules that keep the skill generic and the checks to run.

Nothing in this repository needs to be built or installed to work; the validator and tests run on Node 18 or newer.
